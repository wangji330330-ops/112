# 八卦枢机 · 术数占卜网页

**在线地址：<https://wangji330330-ops.github.io/112/>**（仓库：<https://github.com/wangji330330-ops/112>）

以**八卦为轴心**的中国传统术数占卜网页。进入即见一个八卦盘：盘心为**阴阳鱼**
（阳之首朝乾、阴之首朝坤，随盘同转，故八方转动而乾坤首尾之位不失），
扇区中卦象（爻）与卦名上下居中排列，外环十二地支。点击某卦 → 八卦盘转动，
该卦之术数列于盘侧；不与八卦相系者，列于**大八卦之下**另成一区。
界面为清晰版：纯白卡片、细边框、无纹理无水墨；八卦盘转动时八方卦名恒保持正立。

## 打开方式

**双击 `index.html` 即可**（file:// 直接运行）。纯静态、零构建、无依赖、不联网、
不需要服务器，也不需要安装任何东西。

## 交互

- **点击卦象** → 八卦盘转动（0.8s 缓动），该卦之术数列于盘侧，盘心显示卦象、卦名与门数；
  八方卦名始终正立可读。
- **点击术数节点** → 直接进入术数页：**无整屏遮罩**，只有面板自右侧滑入、正文淡入，
  八卦盘全程可见；返回同理，面板滑出、盘转回原位。
- **起课**：每门术数页有「源流与原理 / 起占方式 / 起课 / 断语 / 术语小释 / 免责」，
  填好表单按「起课」即排盘；「重来」清盘，「复制结果」留底。
- **Esc** 返回上一层；顶部面包屑随时跳转。
- **地址可分享 / 刷新不丢**：`#/gua/qian`（某卦分支）、`#/art/qimen`（某门术数）。
- 手机端：八卦盘缩放，术数列表改为自下方升起的卷轴面板。

## 排盘的可复核之处

干支历不查表而是**算**出来的：以 Meeus 低精度公式求真太阳黄经，迭代求节气时刻
（误差一至数分钟），故年柱以立春为界、月柱以十二节为界、日柱以 23 时换日、时柱依五鼠遁。
引擎自带 110 项回归断言（`node tools/core-test.cjs`），其中锚点与经典值包括：

- 日柱锚：1949-10-01 甲子日、2000-01-01 戊午日、2024-01-01 甲子日
- 四柱：2024-05-01 13:00 → 甲辰年 戊辰月（月令清明）乙丑日 癸未时
- 六十四卦名与卦序、京房八宫（八宫各统八卦、覆盖 64 卦不重不漏）、纳甲、旬空
- 紫微安星以《紫微斗数全书》三例校验（27日木三局→戌、13日火六局→亥、6日土五局→未）
- 八宅游年（乾命生气在兑、坎命生气在巽…）、玄空年星（1864 一白、1984 七赤、2024 三碧）、
  2024 年盘九宫合通行盘、二十四山（子山为正北 0°）
- 大衍筮法爻概率合古法 6:1/16、7:5/16、8:7/16、9:3/16；三钱摇卦合 1/8、3/8、3/8、1/8

`node tools/arts-test.cjs` 对 31 门术数各跑多种输入（共 180 用例），校验 `cast`/`view` 不抛错、
输出无 `undefined/NaN`。`tools/cdp.mjs` 可驱动 Edge 检查真实页面并截图。

## 诚信说明（重要）

- 排盘力求合于古法，**凡简化、异说、自撰之处，页面内均以警示条显式标注**
  （如太乙的积年锚点、皇极经世的元会锚点、紫微不做公历农历换算、七政四余非真历算、
  铁板神数条文为编者自撰、签诗为自撰签诗、相术量表为本站所定、扶乩乩文为随机生成等）。
- **断语一律为参考白话，不是古籍原文**；不写生死、疾病确诊、投资盈亏、婚姻必成必败。
- 术数为传统文化之数术模型，结果仅供文化体验与自省，**不构成医疗、财务、法律、
  婚恋等任何决策依据**。
